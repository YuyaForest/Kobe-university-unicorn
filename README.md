# ✨ ユニコーンゲットだぜ！ (Unicorn Get!) ✨

SEC Form D の実データ分析と連動した、単一ファイル構成のキュートなもぐらたたき風ブラウザゲームです。  
卵の中からパカッと顔を出すユニコーンをゲットして、将来のユニコーン企業を発掘しよう！

## 🎮 ゲーム概要

* **タイトル**: ユニコーンゲットだぜ！
* **ジャンル**: 30秒スコアアタック・モグラ叩き風アクションゲーム
* **動作環境**: PC / スマホの各種主要ブラウザ（Google Chrome, Safari, Edge, Firefox 等）
* **特徴**: サーバーやビルドツールを一切使用せず、単一の `index.html` ファイルのみで動作します。

---

## ✨ 主な機能と特徴

1. 🦄 **パカッと割れる可愛い卵のアニメーション**
   - 割れ目の入った卵の殻から、ユニコーン（🦄）がパカッとパステルカラーの顔を覗かせるキュートな演出。
2. 💰 **1匹ゲット＝10億ドル！ダイナミックなスコア**
   - ユニコーンを1匹タップするごとに「10億ドル」の獲得金額が加算されます。
3. ⏱️ **30秒間のスコアアタック**
   - 制限時間は30秒。残り5秒を切るとタイマーが赤く点滅して緊張感がアップします。
4. 📊 **SEC Form D 2026-2Q データ連動スタッフロール**
   - タイムアップ後、捕まえたユニコーンの数（頭数）に応じて、米国 SEC Form D データから分析・抽出した**「将来のユニコーン候補企業 40 社」**が解禁されるスタッフロール（エンドロール）画面を搭載！
   - スムーズな自動スクロール ＆ 手動スクロール両対応で、解禁された各企業の所在地・業種・調達規模を確認できます。

---

## 🚀 遊び方 (How to Play)

1. 当リポジトリをダウンロード（または Git クローン）します。
2. `index.html` をダブルクリックして、お好きなブラウザで開きます。
3. **「✨ ユニコーンゲットだぜ！ ✨」** の画面で、卵から顔を出すユニコーンを素早くタップ！
4. 30秒経過後、タイムアップ画面から **「🦄 発掘ユニコーン企業 スタッフロールを見る」** をクリックして、解禁された企業リストをお楽しみください。

## 📊 データソースについて

スタッフロールに登場する企業データは、米国証券取引委員会（SEC）の **Form D 提出データ (2026-2Q)** から、非上場で大規模調達を実施した有望なテクノロジー・バイオ・AI・DeepTech等の成長事業会社 40 社を独自抽出・分析したものです。
